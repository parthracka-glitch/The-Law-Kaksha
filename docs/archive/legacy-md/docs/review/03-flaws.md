# 03 — Flaw Register

## 🚨 Must Fix Before Launch (Blockers + Critical Highs)

- [ ] **SEC-001** — Payment verification accepts ANY signature (free products for everyone)
- [ ] **SEC-002** — Hardcoded JWT secret in source code
- [ ] **SEC-003** — Hardcoded Razorpay secret in source code
- [ ] **SEC-004** — CORS policy is fully open (allows all origins)
- [ ] **SEC-005** — No Razorpay SDK integration (payments are simulated)
- [ ] **DATA-001** — JSON file database: no ACID, no concurrency, data loss on crash
- [ ] **SEC-006** — Admin credentials and passwords displayed on login page
- [ ] **SEC-007** — Unauthenticated endpoints expose all student PII
- [ ] **SEC-008** — No rate limiting on auth endpoints (brute-force)
- [ ] **SEC-009** — No security headers (helmet, CSP, HSTS)
- [ ] **DATA-002** — No backup, no PITR, no restore mechanism
