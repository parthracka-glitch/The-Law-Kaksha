# Learnings & Field Observations

## Commands that work
- `git -C thelawkaksha check-ignore -v docs/audit/private/SECURITY_NOTES.md` [gemini 2026-10-05 src:.gitignore verified] — Confirms private security notes file is properly gitignored.
- `git status` / `git branch` executed within `thelawkaksha` directory [gemini 2026-10-05 src:thelawkaksha/.git verified] — Confirms active git working tree.

## Gotchas
- Workspace root `NIRVANAA STUDIOS PROJECTS/The Law Kaksha` is not a git repository; the repository root is `thelawkaksha/` [gemini 2026-10-05 src:. verified]. All git commands and repo paths must be scoped to `thelawkaksha`.
- `backend/data/lawkaksha_db.json` updates its `lastActiveAt` and `updated_at` properties during runtime operations or dev testing [gemini 2026-10-05 src:backend/data/lawkaksha_db.json verified]. Verify unstaged changes before committing to avoid staging unintentional runtime state.
- `frontend/AGENTS.md` is auto-generated by Next.js 16 (`node_modules/next/dist/server/lib/generate-agent-files.js`) [gemini 2026-10-05 src:frontend/AGENTS.md verified]. Do not overwrite or delete subfolder agent files.

## Things that failed and why
- Running `git status` at parent workspace path failed with `fatal: not a git repository` because only the child folder `thelawkaksha/` contains `.git` [gemini 2026-10-05 src:. verified].

## Conventions discovered
- Monorepo convention: Frontend resides in `frontend/` (Next.js 16, React 19, Tailwind v4); backend resides in `backend/` (Express.js, Mongoose, local JSON DB fallback) [gemini 2026-10-05 src:package.json verified].
- Backend tests utilize Node.js built-in test runner (`node --test`) without Jest/Mocha dependency overhead [gemini 2026-10-05 src:backend/package.json verified].
