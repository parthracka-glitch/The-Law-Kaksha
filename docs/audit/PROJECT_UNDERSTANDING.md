# Project Understanding: The Law Kaksha

## Overview
The Law Kaksha is an online learning and digital codex platform for CA Foundation & CSEET Business Laws.
It provides:
- Next.js 16 (React 19, Tailwind v4) frontend
- Express.js backend (MongoDB Atlas + local JSON DB fallback)
- DRM-protected in-browser PDF Reader with anti-download, anti-screenshot, and watermark features
- Course purchase & multi-course entitlement stack
- Student learning dashboard with free resources for unregistered/unpurchased students, and unlocked course codices for purchased students.
