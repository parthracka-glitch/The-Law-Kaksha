# ⚖️ The Law Kaksha — Premier CA Law Academy & Study Portal

> **Next-Generation Academic Platform & DRM-Secured Study Workspace for CA Foundation, CA Intermediate & CA Final Law Aspirants.**

---

## ✨ Features & Architecture

- **📚 Dual-Volume Law Reviewer Codexes**: Companies Act 2013, Economic & Business Laws, 9-Attempt Solved RTPs/MTPs.
- **🛡️ In-App DRM Reader**: Hardware-bound 2-device license enforcement, dynamic anti-piracy cryptographic watermark, and screenshot/copy interception.
- **🎓 Student Workspace (`/student`)**: Personalized active materials, live streak counter, 1-minute daily MCQ drill, and instant module upgrades.
- **⚡ Interactive 5-Pillar Model Answer Builder**: Step-by-step scoring architecture comparing average answers with high-scoring ICAI model drafts.
- **💳 Multi-Step Checkout & Tax Invoices**: Razorpay gateway simulation, 1-click promo code discounts (`CALAW20`, `RANKER10`), and printable official GSTIN tax invoices.
- **📊 Faculty Admin Command Desk (`/admin`)**: BlueDart/DTDC courier dispatch exports, live orders tracker, and promo code manager.

---

## 🛠️ Technology Stack

- **Framework**: Next.js 16 (App Router with Turbopack)
- **Language**: TypeScript
- **Styling**: Tailwind CSS & Modern Glassmorphism Design Tokens
- **Icons**: Lucide React
- **SEO**: Schema.org JSON-LD structured data for Educational Organization, Courses, and Reviews.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/parthracka-glitch/The-Law-Kaksha.git
cd The-Law-Kaksha
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.
